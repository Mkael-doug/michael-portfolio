# 🌐 3D Awwwards-Level Developer Portfolio

### Construído com React, GSAP, Three.js, TailwindCSS

Este é um portfólio de desenvolvedores 3D totalmente animado e interativo, projetado para impressionar clientes, recrutadores e gerentes de contratação. É mais do que um portfólio — é uma experiência web construída com código em nível de produção, animações baseadas em rolagem e melhores práticas do mundo real.

>⚡ Inspirado em sites de nível Awwwards — criado com React (Vite), TailwindCSS, GSAP, React Three Fiber e Drei.

## 🚀 Tech Stack


| Tecnologia | Descrição |
| :--- | :--- |
| **React (Vite)** | Servidor de desenvolvimento rápido e agrupamento de produção |
| **TailwindCSS** | Estilo utilitário em primeiro primeiro para componentes |
| **GSAP** | Animação baseada em rolagem e lógica de movimento |
| **Three.js** | Cenas 3D com tecnologia React Three Fiber |
| **Drei** | Ajudantes úteis para renderização 3D |

---

## 📁 Features
- 🔥 Hero Section 3D com planeta animado e anel dourado.
- 🧩 Barra de navegação deslizante suave com animações de links escalonadas.
- 🎯 Resumo de serviço acionado por rolagem com movimento horizontal de palavras.
- 🖼️ Seção de projetos com sobreposições de foco e visualizações interativas.
- ✍️ Sobre a seção com revelação de imagem clip-Path + texto da máquina de escrever.
- 🏁 Resumo de contato baseado em Marquee e CTA.
- 💼 Totalmente responsivo e acessível em todos os tamanhos de tela.

## 📦 Setup & Instalação
```
git clone https://github.com/Mkael-doug/michael-portfolio.git
cd awwwards-portfolio
npm install
npm run dev
```
> Open http://localhost:5173 in your browser

---
## 🛠️ Dicas de personalização
Alterar texto, imagens e links em/constants/index.js

Atualizar modelos 3D e cena em Hero.jsx

Adicione suas próprias informações de contato em Contact.jsx

Ajuste cores, fontes e layout via tailwind.config.js
